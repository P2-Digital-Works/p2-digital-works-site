# P2 Digital Works implementation plan

**Goal:** Deliver the approved lead-generation website as runnable, deployable source.
**Architecture:** Semantic static frontend with shared validation and a small server-side quote webhook adapter. Preview requests stay in browser memory and download explicitly; configured delivery requires server acknowledgment.
**Tech stack:** HTML, CSS, ES modules, Node 22+, built-in node:test; Vercel and Netlify adapters.
**Spec:** DESIGN.md, grounded in the approved proposal and current user request.

## Global constraints
Preserve black logo; use navy, teal, amber and white. Label every demo. No unverified business claims. Project fee plus optional care. Six sections, mobile and keyboard access, crawlable metadata. No PII logging or browser persistence. Local/deployable handoff.
